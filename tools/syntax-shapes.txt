# left over on either side.

# optional.  Taken from documents 01 to 17, where these were measured, and
# from BCOMP's statement compilers where no page covers them.

# The names Solo's compiler carried from SD Core in the first sync (LSOLO 52,
# 18 Oct 2026) and the shapes of the forms that grew at the same time.  The
# shapes are SD Core's, from its syntax card and its shapes file; each was held
# against Solo's own BCOMP and kernel source, and the card is the only place
# they are described (no User page of this set describes these names yet, so
# there is no link to one).  Where SD Core's line said a thing that Solo's
# source does not (FCONTROL's FC$CRLF), the line here follows Solo's source.

# outside the account's own directory needs the os switch.
